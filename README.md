## 📋 Descripción del Proyecto

Este repositorio contiene los entregables del proyecto final del curso de **Diseño e Implementación de Arquitectura Empresarial**, desarrollado bajo la metodología **RUP (Rational Unified Process)**, el framework **TOGAF** y el estándar de modelado **UML**, haciendo uso de la herramienta **Visual Paradigm**.

El proyecto es desarrollado de forma iterativa e incremental a lo largo del ciclo académico, abarcando el modelado del negocio, ingeniería de requerimientos, arquitectura del sistema y diseño de soluciones empresariales.

## 📌 Instrucciones para Subir Diagramas

1. Exporta el diagrama desde **Visual Paradigm** en formato `.png` o `.pdf`
2. Nómbralo de forma descriptiva, por ejemplo: `CUS-Negocio-v1.png`
3. Colócalo en la carpeta correspondiente según el tipo de diagrama
4. Realiza un commit con un mensaje claro: `feat: agregar diagrama de casos de uso del negocio`
